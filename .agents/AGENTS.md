# Diretrizes do Projeto - Zoo Sonoro

- **Tecnologias**: HTML5, CSS3 e JavaScript Vanilla puro (sem frameworks ou compiladores).
- **Estética**: Cores vibrantes, bordas arredondadas, sombras suaves, tipografia com fontes grandes (Fredoka / Nunito) voltadas para crianças pequenas.
- **Estrutura**:
  - `index.html`: Elementos semânticos e responsivos.
  - `style.css`: Sistema de design, variáveis CSS, animações keyframe (`bounce`, `wiggle`, `glow`).
  - `script.js`: Array de animais, manipuladores de áudio HTML5 e partículas.
  - `images/`: Imagens dos animais em formato JPG/PNG.
  - `audio/`: Sons dos animais em formato MP3.
